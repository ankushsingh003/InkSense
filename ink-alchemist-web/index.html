A 3D-CNN + Transformer model trained in PyTorch detects ink that is invisible in any single CT slice — by learning from a 32-slice stack of surface-volume scans. This page shows a lightweight browser-side heuristic preview (luminance + saturation scoring). The trained model runs offline via train.py / evaluation.py.

What is this?

InkSense is a research pipeline for the Vesuvius Challenge ink-detection task — segmenting the traces of carbonised ink left on papyrus scrolls from Herculaneum, buried by the eruption of Mount Vesuvius in 79 AD. X-ray micro-CT scans reveal surface topology but ink is nearly invisible by reflectance; only subtle density differences in the CT volume betray its presence.

The model processes 32 consecutive CT slices per tile, building a volumetric understanding before projecting down to a 2D ink-probability mask. Self-attention runs on 1,024 tokens per tile (8× spatial downsampling) rather than 65,536 pixels, keeping memory manageable on a consumer GPU.

Note

This browser demo does not run the trained model. It uses a pixel-luminance heuristic to produce a fast, approximate preview. All quantitative results come from the offline Python pipeline.

Pipeline

End-to-end from raw TIFF slices to evaluated metrics.

01

Preprocess

16-bit TIFF slices scaled to uint8 and written to a memory-mapped .npy file. RAM stays at one slice; a 1.7 GB volume (Fragment 1) streams safely on any machine.

python data_preprocessing.py --fragment 1
↓
02

Spatial Split

Bottom 20% of each fragment is held out as the validation band. Train tiles must end above this boundary — zero pixel overlap guaranteed by a unit test.

↓
03

Train

AdamW + cosine schedule, mixed precision (AMP), gradient norm clipping. Best checkpoint selected by validation F0.5. Optional W&B logging.

python train.py --train_fragments 1 --epochs 30
↓
04

Evaluate

Sliding-window inference (overlapping tiles, averaged), threshold sweep on validation band, morphological open/close denoising. Outputs metrics.json.

python evaluation.py --fragment 1 --region val
↓
05

Visualise

4-panel figure: IR scan, ground truth, probability map, and TP/FP/FN error overlay (green = TP, red = FP, blue = FN).

python visualize_impact.py
